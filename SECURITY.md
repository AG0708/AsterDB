# Security Policy

AsterDB is an experimental database and is not suitable for public or
security-sensitive deployment. It has no authentication or TLS in its core
release and binds to loopback by default.

Please report suspected vulnerabilities privately to the repository owner. Do
not include secrets, production data, or destructive proof-of-concept payloads.
Supported versions and a private reporting channel will be listed when the first
public release is published.

See `docs/THREAT_MODEL.md` for the current security boundary.
